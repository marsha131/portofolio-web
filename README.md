## Deskripsi

Project web portofolio menggunakan Laravel 13 untuk tugas Pemrograman Web Lanjut.

## Cara Menjalankan

```bash
git clone https://github.com/marsha131/portofolio-web
cd REPO
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

* Laravel 13
* PHP 8.3
* MySQL
